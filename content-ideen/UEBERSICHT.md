## So funktioniert dieser Ordner

- **Neue Idee einfach hinzufügen:** Am Ende der passenden Datei ergänzen, Datum dazu schreiben
- **Idee umgesetzt?** Mit `✅` markieren, Datum der Umsetzung ergänzen
- **Schnell erfassen:** `/capture` in Claude Code — ich lege es dann hier ab
- **Erweiterbar:** Neue Kategorie? Einfach neue `.md`-Datei anlegen und hier eintragen

---

## Schnell-Erfassung

Neue Idee? Tippe in Claude Code:

```
/capture [deine Idee] → content-ideen
```

Ich sortiere sie dann in die richtige Datei ein.
